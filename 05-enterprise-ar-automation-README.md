# Accounts receivable dashboard

This project improves management visibility over receivables. The previous report was a customer summary circulated by email. The dashboard adds customer, staff and ageing views so that management can focus collection follow-up.

Excel was chosen because the team already used it for accounting and reporting. The workbook can be inspected and shared through the existing email process.

## Public workbook

- 98 current invoices and 80 prior-period invoices.
- Current receivables: 51,055,875,000 VND.
- Overdue receivables: 9,802,728,000 VND (19.2%).
- Six sheets: Dashboard, Current AR, Prior AR, Analysis, Collection Follow-up and Checks.
- Customer, staff and ageing breakdowns reconcile to the invoice ledger.

The dashboard gives management a clearer view of receivables and helps focus collection follow-up.

## Files

`reports/AR_Intelligence_Reconciliation_DEMO.xlsx` contains the full public reporting model. `assets/` contains website chart snapshots generated from that workbook.

## Public data

Names, document identifiers and project references have been replaced. Financial amounts have been changed consistently. Original ERP screenshots, customer directories, project registers and internal notices are excluded. The public workbook has no ERP connection or posting permissions. Balances over 60 days are an ageing review category, not an impairment conclusion.
